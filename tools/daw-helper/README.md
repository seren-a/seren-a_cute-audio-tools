# daw-helper

> it's more fun when it looks girly

Helfer rund um DAWs und Plugins: Presets umwandeln, Sessions übertragen, Kleinkram automatisieren. Jeder Helfer liegt in einem eigenen Unterordner mit eigener README.

| Helfer | Was er tut |
| --- | --- |
| [dearvr-konverter](dearvr-konverter/) | dearVR-Presets lesen, vergleichen, bearbeiten und umwandeln: Reaper-.ini, PRO v1 ↔ PRO 2, .vstpreset / .aupreset / .fxp, Excel/CSV – als Browser-Oberfläche (Preset-Werkstatt) und Python-Kommandozeile. |

Passende REAPER-Scripts (Spuren nach Plugin auswählen, FX auf Auswahl kopieren) liegen im Repo [seren-a-reaper-scripts](https://github.com/seren-a/seren-a-reaper-scripts) unter `tools/track_fx_helpers`.
