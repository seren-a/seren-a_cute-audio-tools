Menüs wegklappen: «Filter» / «Oben» / «UI» oben rechts oder Tasten F · O · U · C (Clear). Rahmen der Fraktal-Blöcke und seltenen Streams: Taste R (an/aus; wenn an, blenden sie mit der Aktivität aus). Farbschema «auto» folgt der Systemeinstellung hell/dunkel; das gesamte Menü färbt sich im Theme mit. Der Hintergrund wird je Theme deckend neu gesetzt – nichts brennt ein, nach dem Ausblenden bleibt die Fläche sauber. MIDI: Web MIDI (Chrome/Edge; Firefox bietet kein Web MIDI – OSC läuft überall). OSC: Node-Bridge UDP :8000 (Skript im Quelltext-Kopf) oder «matrix-monitor-server» (HTTP + WebSocket in einem, automatischer Verbindungsaufbau beim Hosting). Max/MSP/Jitter/RNBO senden OSC an localhost:8000 ([oscformat] → [udpsend localhost 8000], RNBO-Runner: OSC remote). Zu viele Streams: die regelmäßigsten laufen verdrängt im kompakten Streifen unten mit, seltene Streams werden hervorgehoben.
