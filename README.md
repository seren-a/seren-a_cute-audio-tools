# oxi-mk2-moss-extended

> it's more fun when it looks girly

Erweiterungen für die OXI One MkII in [DrivenByMoss](https://github.com/git-moss): Mixer-Ansichten **Send 16** und **Send 32**, dazu Mix 32/64 und Plugin 32. Liegt hier, weil es für mehr als eine DAW gilt.

| Ordner | DAW | Stand |
| --- | --- | --- |
| `reaper/` | Reaper (moss4reaper 26.6.5) | v8.3, läuft (`bauen.sh` baut und installiert das Jar) |
| `bitwig/` | Bitwig | v8.2 geparkt, noch nicht getestet |
| `oxi-mixer-views-v0.5/` | Bitwig + Reaper | ältere Patches, überholt durch die beiden oben |

Push auf den Encodern ist Send an/aus (Mute); Pre/Post macht in Reaper die E16 (siehe `oxi-e16-reaper` in [seren-a-reaper-scripts](https://github.com/seren-a/seren-a-reaper-scripts/tree/oxi-e16-reaper)). Wenn DrivenByMoss die OXI nicht hat, übernimmt in Reaper das Puzzle: [`oxi-puzzle`](https://github.com/seren-a/seren-a-reaper-scripts/tree/oxi-puzzle).
