# synth-surfaces

> it's more fun when it looks girly

Control-Surfaces für Synthesizer: kleine Seiten/Skripte, die per MIDI/OSC
Synth-Parameter sichtbar und steuerbar machen.

**Status:** Platzhalter – hier entsteht das erste Tool. Ordner-Struktur pro
Surface: Skript/Seite + kurze README (Zweck, MIDI-CCs/OSC-Adressen, Aufruf).

Teil der [cute-audio-tools](../../README.md)-Sammlung.
